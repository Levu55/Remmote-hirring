Remote Hiring & Recruitment Platform
A comprehensive platform designed to streamline remote hiring, manage candidates, and coordinate international recruitment processes efficiently.

Key Features
Job Posting & Management: Create, publish, and update job openings for remote roles across various departments.

Candidate Tracking: Track applicant pipelines from initial application to final offer stage.

Remote Assessment & Evaluation: Tools to schedule interviews, review portfolios, and evaluate candidate performance remotely.

Team Collaboration: Share feedback, add internal notes, and score candidates collaboratively with hiring managers.

Getting Started
Prerequisites
Node.js (v18.x or higher)

npm or yarn

Git

Installation
Clone the repository:

Bash
git clone https://github.com/Levu55/Remmote-hirring.git
cd Remmote-hirring
Install dependencies:

Bash
npm install
Set up environment variables:
Create a .env file in the root directory and add the following:

Code snippet
PORT=5000
DATABASE_URL=your_database_url
JWT_SECRET=your_secret_key
Run the development server:

Bash
npm run dev
